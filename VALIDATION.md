# Validation record

Test machine: Windows x64, NVIDIA GeForce RTX 4090 (24 GiB), driver 617.14. Release build: MSVC 19.44, CUDA 12.8, OptiX 9.1, Qt 6.8.3. Tested September 30, 2026.

## Automated correctness checks

`fornaio_cli --self-test` passes:

- Transparent, 50%-opaque and opaque card stacks compared against an independent brute-force CPU ray/triangle tracer. Constant-mask scenes have zero GPU/CPU difference at the tested settings.
- Bilinearly sampled fine-strand patterns, mask vertical flip, repeated mask coordinates, and separate mask/output UV sets.
- An 80-card stack with low opacity, with no maximum transparent-layer count.
- Front-side sampling, flipped normals, grazing interpolated normals, finite ray range, and no self-occlusion on an isolated card.
- Positive-area UV overlap rejection in strict mode, acceptance of shared UV edges, missing/non-finite UV rejection, out-of-tile UVs, and degenerate geometry rejection.
- Mirrored UV2 islands with unchanged UV1, reversed geometry winding/normals, and rejection of genuine overlap inside mirrored islands. Mirrored-UV GPU baking is compared with the CPU reference.
- Default overlap averaging: GPU/CPU agreement, contribution from both occluded and unoccluded surfaces, half-open shared-edge coverage in both winding directions, and preservation of hard errors for invalid UVs. A 36,520-triangle user FBX with seven overlapping triangle pairs also completed a UV1-to-UV2 test bake using an opaque test mask; the user's mesh was not changed.
- Optional opaque occluder: GPU/CPU agreement with a UV-less casting mesh, opacity independent of the hair mask, two-sided casting, maximum-distance clipping, exclusion from the output atlas, rejection of invalid casting geometry, and restoration of the original result when removed. Real-file integration also imports a UV-less OBJ occluder. UI coverage checks load/remove and retention of the previous bake's head-mesh snapshot.
- Cancellation before tracing and during an in-progress bake; island-preserving padding.
- PNG roundtrip of all 65,536 grayscale values without loss of precision; both 8-bit and 16-bit output.

`scripts/integration_tests.py` passes:

- Actual FBX and OBJ imports, named FBX UV layers, and OBJ's single UV layer.
- Imported transformed bounds checked against values independently generated by Blender; nonuniform scale, rotation, translation, and a negative scale are included.
- Real imported-file GPU results match the CPU reference within two 16-bit quantization steps.
- Identical results from PNG, TGA, and TIFF masks; Unicode mesh/output filenames.
- Overlapping selected UV sets rejected with `--strict-uv`; nonexistent UV selections rejected in both modes.
- Transparent-mask output is white; PNG CRCs, 16-bit grayscale header, and linear gamma tag verified.

- Texture transfer: a 64×64 RGB albedo and roughness set is transferred between two 8×8-grid OBJ files whose UVs are mirrored horizontally. The job runs from JSON with relative paths, on both the GPU and the CPU reference. All 128 target triangles are matched exactly, and every texel matches the mirrored source within one 8-bit level, including the border texels. A rerun is refused while outputs exist, and `--overwrite` permits it.

`fornaio_cli --self-test` also covers texture transfer:

The self-test also checks that object pairing excludes neighbouring meshes. `fornaio_ui_tests` (eight stages) checks the tab layout, job building from loaded meshes and textures, automatic set/material/prefix guesses, the JSON round trip, and mutual exclusion of AO and transfer GPU jobs.

The GUI was exercised with the 400-card FBX, including masked geometry, a completed asynchronous bake, AO preview, and PNG export through the application's export implementation. Screenshots and raw reports are in `artifacts/` in the workspace. The portable package is additionally checked with development tool paths removed from the child process environment.

`fornaio_ui_tests` passes seven Qt test stages (five regression scenarios plus setup/cleanup): real wheel events over focused dropdowns and spin controls scroll the panel without changing values or losing the bake; explicit settings changes and cancellation preserve the completed result and original UV/mask preview mapping; a bake finishing while the export dialog is open cannot replace the result being exported; a 20,000-face stacked-UV scene has bounded overlap diagnostics while invalid UVs on the final face are still detected; and loading/removing a UV-less head preserves the previous bake's original occluder snapshot. Preferences used by the tests are isolated from the user's settings. The occluder addition was verified October 1, 2026, including a complete GUI bake of the supplied hair/head example.

Windows recorded `AppHangTransient` for the reported scrolling incident. The previous UI accepted wheel edits, discarded the completed bake on any settings change, and synchronously enumerated all overlap pairs when UV selection changed. The regression changes address those paths; no crash dump was available to establish any additional failure cause.

## RTX 4090 measurements

Fixture: `samples/hair_400_cards.fbx`, 400 curved cards, 4,800 triangles, shared strand mask and unique AO UV atlas. Settings: 256 rays per subpixel sample, 2×2 supersampling, 8-pixel padding, unlimited ray distance, automatic bias. Timing includes validation, acceleration construction, GPU tracing, readback, and padding; PNG compression is excluded.

| Resolution | Bake time | Explicit GPU buffers |
|---|---:|---:|
| 2048 × 2048 | 1.717 s | 49.35 MiB |
| 4096 × 4096 | 7.473 s | 193.35 MiB |

Buffer counts exclude CUDA/OptiX context, driver cache, and viewport allocations. Timings use a warmed OptiX compilation cache. First launch can take longer. Performance depends on card depth, mask coverage, UV occupancy, ray distance, and other GPU work. These are generated-fixture measurements, not guarantees for a production asset.

## Remaining practical limits

Tests cover generated fixtures and one user-supplied FBX, not every FBX exporter or malformed file. The user's hair mask was not supplied. The 3D preview uses 8-bit AO and ordered opacity dithering; baking/export use graded transmission and full float/16-bit precision. Noise remains sampling-dependent. Running the portable app on a separate clean Windows installation has not been tested; the package is validated locally with development paths removed.
